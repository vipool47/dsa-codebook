## Repository Structure

```text
src/
├── <topic>/                  # array, string, heap, ...
│   ├── easy/                 # difficulty grouping where applicable
│   ├── medium/
│   ├── hard/
│   └── learning/            # concepts and templates
├── <topic>/ListNode.java     # shared helpers live with their topic
└── z-resources/              # diagrams referenced by solutions
```

File names describe the problem (e.g. `src/array/medium/TwoSum.java`), and each package mirrors its folder path.
